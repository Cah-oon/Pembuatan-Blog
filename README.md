# Nexora Blog

Blog modern untuk teknologi, firmware, produk, dan affiliate.

## Fitur
- Landing page modern
- Halaman blog dan detail artikel
- Dashboard admin dengan menu lengkap
- Logo profesional dan siap dipakai
- Struktur folder siap dikembangkan

## Jalankan lokal
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
Proyek ini siap di-deploy ke Vercel, Netlify, Railway, atau container Docker.
